# Українська наукова фантастика, 1920–2020

Дослідження Олега Шинкаренка, українського письменника й докторанта Печського
університету (Докторська школа літературознавства та культурології), про те, як
українська наукова фантастика пройшла шлях від технокомуністичних утопій 1920-х
до іронії та сумніву пострадянських десятиліть.
