# Мої книги

<div class="articles-intro" markdown>
П'ять книжок українською та один англійський переклад — від сюрреалістичних оповідань і постапокаліптичних романів до політично загостреної сатири. Кожна книжка з метамодерної перспективи досліджує ідентичність, мову, пам'ять і український досвід.
